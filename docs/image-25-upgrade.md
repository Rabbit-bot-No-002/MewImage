## 已实现

### 2026-09-12：编辑协议放行与同步能力保护

- 共享请求校验已允许 `OpenAiImage` 的 Images API 与 Responses API 携带编辑信息，其他服务商和自定义 JSON 继续明确拒绝；普通参考图最多 10 张，独立遮罩不占名额但继续计入文件、请求体和内存硬限制。
- Images 编辑请求使用 `/v1/images/edits`、重复 `image[]` 与唯一 `mask`；Responses 图片工具使用独立 `tools[].model`、`action=edit` 和 `input_image_mask.image_url`，顶层主模型不被图片模型覆盖。Direct Responses 在发送前复核遮罩 Data URL 的 PNG MIME、长度和 SHA。
- 后端健康接口声明 `image_editing_v1=true`。代理生成会在上传前检查能力；云同步检测到持久化编辑任务时也会先检查健康能力，缺省、旧后端或异常响应均在资产上传及 `/api/sync/push` 前终止。没有编辑任务的同步不依赖新能力。
- 模拟上游测试覆盖完整 Images multipart 的参数、底图/遮罩分离与原字节校验，以及 Responses 顶层模型、工具模型、输入图片和遮罩的位置。未调用真实付费上游，不能据此宣称所有账号或中转站兼容。
- 协议实现依据 [OpenAI 图片生成指南](https://developers.openai.com/api/docs/guides/image-generation)、[Images 编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit) 与 [Responses create](https://developers.openai.com/api/reference/resources/responses/methods/create)；中转站仅采用其文档明确承诺的 Images 编辑路线。
- 当前完整自动化结果：后端 87、前端 141、共享层 49 项测试通过；工作区检查、严格 Clippy、WASM 检查、Trunk Release 与 `git diff --check` 通过。当前工具会话没有可用浏览器，因此未把浏览器交互列为通过。

- 受控本机上游测试已穿过真实 `invoke_openai_image` 网络分支：Images 请求到达 `/v1/images/edits` 且包含 `image[]` 与唯一 `mask`；Responses 请求到达 `/v1/responses`，顶层保持主模型，图片模型和遮罩位于图片工具内，普通输入内容只有提示词与底图。测试未连接真实收费服务。

### 2026-09-12：已有 Alpha PNG 遮罩导入

- 局部修改模式增加“导入同尺寸 Alpha PNG”：读取前仅接受单文件，客户端校验 PNG MIME、魔数、32 MiB 上限、实际尺寸和至少一个完全透明像素；不符合条件时不改变草稿。
- 导入遮罩作为本地草稿 Blob 独立保存，不加入普通参考图、不占 10 张名额，也不进入同步、备份或模板。应用时以它为遮罩底层叠加画笔/橡皮，再编码为带正式 SHA 和资源角色的新遮罩。
- 替换遮罩会同时清空当前手绘选区，并作为一个撤销步骤；撤销/重做、清空图层可恢复此前遮罩与笔画。关闭并保存编辑器时回收仅由内存撤销历史引用的旧遮罩，删除会话草稿及清空本地草稿会回收当前遮罩 Blob。
- 草稿增加可选遮罩引用且保持版本 1；旧草稿缺省兼容。恢复时重新执行 PNG、尺寸和透明区域校验，失败不会忽略遮罩继续生成；应用前还会核对已加载遮罩 ID 与草稿一致。
- 单元测试覆盖遮罩替换、去重、模式隔离、清空、撤销、资源引用和旧字段兼容；前端测试增至 139 项，严格 Clippy 通过。浏览器文件选择、Canvas Alpha 语义和 IndexedDB 配额故障仍需实测。
- 本批格式检查、工作区测试（后端 83 / 前端 139 / 共享层 48）、工作区与 WASM 检查、严格 Clippy、Trunk Release 和 `git diff --check` 通过；未调用真实上游。

### 2026-09-11：超限底图工作副本

- 打开超过 4096 边长的底图时，仅计算建议尺寸，先展示原图和等比工作尺寸并等待确认；取消不改旧草稿或原资源。确认后创建 PNG 工作副本，编辑坐标和最终底图/遮罩统一使用工作尺寸。
- 本地草稿增加可选原始底图尺寸，不改变草稿版本、同步或 ZIP 格式；旧草稿缺省不缩小，已确认的草稿恢复时可重建工作副本，无需再次确认。同尺寸校验仍拒绝原资源与记录不符的情况。
- 原图解码按原始尺寸领取编辑内存预算，不仅按缩小后的画布计费；完成缩小后释放原始图片和 URL。单文件 32 MiB 与编辑 4096 边长限制不放宽。
- 未成功解码或缩小时不自动保存替换草稿；等待预算或加载期间允许关闭，加载成功后自动安排草稿保存。浏览器插值效果、超大原图峰值内存与关闭时资源释放尚需实测。
- 新增超限确认、原元数据不变、已确认草稿恢复、缩放尺寸一致性和旧字段缺省测试；前端单元测试 136 项通过。

### 2026-09-11：编辑应用事务确认

- 应用事务与后台工作区保存互斥，防止旧快照晚返回覆盖新输入。编辑参数与普通选择保存共用修订号；取消、切换会话或改变选择会中止尚未确认的事务，失败后重新安排当前选择保存。
