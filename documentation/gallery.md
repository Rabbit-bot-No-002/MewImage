# 会话、画廊与收藏

> 会话与草稿的归属、结果画廊、图片详情、全屏预览、收藏夹与本地数据分层。

会话把草稿和任务组织在一起，画廊负责翻阅结果，收藏夹跨会话保留你在意的图片。三者都建立在同一份本地 IndexedDB 数据上。

## 会话系统

每个会话保存独立草稿、任务 ID 列表和更新时间。新会话首次生成时可以根据提示词自动生成标题；重命名后按钮文字立即响应式更新，不需要刷新页面。会话支持重命名与删除，使用项目内自定义浮层。

| 行为 | 说明 |
| --- | --- |
| 默认显示 | 会话栏默认显示 5 个会话 |
| 归档 | 超出一行的会话按创建时间优先归档最早的；归档按钮是单图标，下拉菜单可切换归档会话 |
| 删除会话 | 普通任务与资源按引用关系清理 |
| 收藏脱离 | 已收藏任务脱离原会话保存，删除原会话不会丢失收藏内容、提示词、参考图和结果图 |

## 单会话项目包

从会话操作区、归档会话列表或数据管理页都能导出单个会话的项目包，文件名格式为 `mew-session-{安全化会话名}-{日期}.zip`；会话名会过滤 Windows 非法字符并限制长度。

项目包包含会话草稿、任务、生成参数、结果原图，以及已使用和尚未使用的会话参考图，但不包含服务商配置、API Key、全局偏好、收藏夹、同步检查点或删除墓碑。

> ⚠️ **导入永远创建副本**
>
> 导入时会创建新的会话、任务和图片 ID，清除收藏状态与旧远程资源地址，并自动切换到导入的新会话。重复导入不会覆盖已有项目，跨站导入后原站点的 Response ID 也会失效。

## 结果画廊

结果画廊位于工作区左侧，运行中、成功和失败的任务统一分页，每页显示 10 条记录；分页条在画廊底部居中，包含上一页、页码选择和下一页，页码选择是轻量滚轮卡片，点击外部自动关闭，也不会超出视口。

卡片使用紧凑横向布局：图片填充卡片左侧并保持与卡片一致的圆角，左上角显示按真实宽高归一化后的常见比例和真实分辨率，右侧显示配置名称和模型名，超长文字截断而不撑大卡片。运行状态卡保持固定布局槽位，生成图片增多时不会下移挤占空间。

| 按钮 | 作用 |
| --- | --- |
| 重新生成 | 用原参数再提交一次 |
| 继续修改 | 进入连续修改，见 [参考图与图像编辑器](editor.md) |
| 收藏 | 立即变色，不依赖刷新，也不改变画廊排序 |
| 失败日志 | 查看失败原因 |
| 删除 | 先立即更新内存 UI，再在后台删除 payload 和写入快照 |
| 发布到模板广场 | 管理员对成功任务可见；带独立遮罩的任务不能直接发布 |

工作台的结果详情与模板详情保持一致：参考图、配置信息和操作按钮固定在右下角。

## 图片详情与全屏预览

点击结果缩略图打开详情页，显示提示词、参考图、配置/模型、真实尺寸、请求与实际质量、格式、审核、数量、创建时间和生成耗时。创建时间按亚洲上海时区显示，格式为年/月/日 24 小时制时/分/秒。长提示词区域有固定最大高度，超出后内部滚动，不挤压底部按钮，并可一键复制。

| 操作 | 说明 |
| --- | --- |
| 复用配置 | 只复用提示词、参考图和历史参数，但使用当前选中的服务商配置；执行后自动关闭详情页 |
| 编辑输出 | 打开编辑器处理该结果；执行后自动关闭详情页 |
| 引用参考图 | 有参考图时可一键引用到当前生成流程，没有时按钮灰置 |
| 删除记录 | 确认浮层显示在详情页上方；取消删除保留详情页，确认后才关闭 |
| 复制图片 / 下载 | 下载文件名用日期与图片短哈希区分，不再追加 `(1)(2)` |

再次点击详情图片进入原图全屏预览，支持滚轮缩放、左键拖拽、下载、关闭按钮和 `Esc` 退出；详情页本身也支持 `Esc` 关闭。图片右键菜单提供复制、下载和编辑。`Esc` 按当前最上层依次关闭菜单、确认框、全屏预览、编辑器和父级详情，不会一次穿透多个界面。

## 全局收藏夹

收藏夹是全局资源，不属于任何会话。入口是顶部品牌区左侧的星形图标，使用独立二级弹层，默认包含「默认」文件夹，并支持新增、重命名和删除；删除前会二次确认，删除后其中的收藏移动到默认文件夹。

| 情况 | 行为 |
| --- | --- |
| 只有一个文件夹 | 点击收藏直接加入 |
| 有多个文件夹 | 弹出文件夹选择菜单，按点击位置和视口自动向上或向下展开，限制最大高度，超出时菜单内部滚动，不越出页面边界 |
| 已收藏的图片 | 再次点击可以移动到其他文件夹或取消收藏 |

收藏卡片与结果画廊保持一致的紧凑宽卡片样式和操作能力：桌面端一行 3 张、共 3 行、每页 9 张，分页复用结果画廊的交互。从收藏夹打开详情后，关闭详情不会连带关闭收藏夹；删除原会话也不会删除收藏夹中的独立任务、结果图和参考图引用。

## 本地数据

画廊相关的数据都放在 IndexedDB 数据库 `mew-image-local` 中：

| store | 内容 |
| --- | --- |
| `kv` | 工作区快照、配置和偏好 |
| `asset_payloads` | v2 旧版图片 Data URL payload，只读兼容并按需迁移 |
| `asset_blobs` | v3 图片 Blob payload，新数据只写入这个 store |

工作区快照包含服务商配置元数据、生成任务、会话、图片资源引用和元数据、收藏状态与收藏文件夹、UI 偏好、同步 checkpoint 和同步删除墓碑。

图片按 SHA-256 去重，任务与图片资源分离，同一张参考图不会在每个任务里重复保存二进制。缩略图最长边约 320 像素，原图按需从 IndexedDB 加载并显示为可回收的 Blob URL；关闭详情或缓存淘汰时只释放 URL，不删除原文件。原图内存缓存是 LRU，默认最多 6 张、约 48 MiB。设备级轻量数据（如 API Key 同步开关、可信设备同步密钥）放在 localStorage。
