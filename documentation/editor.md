# 参考图与图像编辑器

> 参考图规则、全屏编辑器的三种模式，以及连续对话式修改的上下文行为。

参考图决定上游看到什么，编辑器决定你如何改图。两者都与「最多 10 张普通参考图」和连续修改的上下文规则绑定。

## 参考图

| 规则 | 说明 |
| --- | --- |
| 上限 | 单次生成最多使用 `10` 张普通参考图；遮罩独立计数，但仍占上传与内存预算 |
| 去重 | 按 SHA-256 自动去重，上传重复图片会直接复用已有资源并加入当前选择 |
| 顺序 | 缩略图常态显示顺序角标和拖动手柄，拖拽改顺序并按该顺序传输给上游 |
| 取消与删除 | 取消选择后仍保留在参考图资源卡片中；删除前二次确认并提示共享引用可能失效 |
| 传输 | 传输前在浏览器端转换为尺寸不变的 WebP，质量 `0.9`，降低 multipart 体积 |

有参考图时请求自动走 `/v1/images/edits`（重复 `image[]` 加唯一 `mask`）；没有参考图时走 generations。编辑输入只支持 `OpenAI Image` 的 `Images API` 或 `Responses API`。

> ⚠️ **历史 11–16 张数据**
>
> 旧任务可能保留了超过 10 张参考图。这类数据可以查看和导入，但不能直接复用或保存，需要你先主动精简。取消精简不会改变工作台，原始资源与顺序保留；连续修改的底图固定保留并占用一个名额。

## 统一图像编辑器

编辑器是全屏工作区，三种模式互相独立：

| 模式 | 用途 | 产物 |
| --- | --- | --- |
| 局部修改 | 涂抹出待修改区域 | 独立底图与遮罩资源 |
| 标记 | 用箭头、框选、文字指明意图 | 普通合成参考图 |
| 草图 | 在空白画布上画构图 | 普通合成参考图 |

三种模式共用缩放、平移、适应窗口、撤销、重做、清空和 `Ctrl+Z`。存在未应用改动时关闭编辑器需要二次确认；编辑器内部的菜单、确认层和父级详情支持 `Esc` 逐级关闭，不会一次穿透多个界面。应用编辑只更新工作台输入，不会自动开始生成；任一资源写入失败时，原工作台和本地草稿都会保留。

## 标记工具

工具栏是紧凑图标组，包含选择、自由画笔、箭头、矩形、椭圆和可再次编辑的文字。选中对象后可以直接拖动并实时预览，文字可以重新编辑，当前工具与模式有明确的填充状态。文字字号按画布短边给出可辨认的默认值，避免合成后模型无法识别。

## 局部修改

局部修改提供画笔、橡皮、笔刷尺寸和同尺寸 Alpha PNG 遮罩导入。待修改区域以透明 Alpha 输出，底图与遮罩使用同尺寸 PNG 工作副本。遮罩不占普通参考图名额，也不会被无提示降格成参考图；两者是不同资源，单文件不超过 32 MiB。

> ℹ️ **遮罩怎么传给上游**
>
> `Images API` 用重复的 `image[]` 字段加唯一 `mask` 提交；`Responses API` 在图片工具内使用 `input_image_mask.image_url` 与 `action=edit`，图片模型属于工具模型，顶层主模型保持独立。支持编辑的服务商不会静默丢弃遮罩，旧后端或不支持编辑的服务商会明确报错。

带独立遮罩的任务不能直接发布为模板广场模板，但它的最终结果图仍可创建普通模板。

## 草图

「绘制草图」是独立入口，使用独立的白色画布，不占用参考图底图。草图和标记应用后都会生成普通合成参考图。

## 草稿与工作副本

| 限制 | 值 |
| --- | --- |
| 保留步数 | 最多 100 步 |
| 操作数据 | 不超过 8 MiB |
| 工作副本最长边 | 4096 px |

编辑草稿按会话保存在当前浏览器。底图超过 4096 边长时需要确认后创建等比工作副本，原图保持不变。最终底图、遮罩与合成图进入正常同步、备份、删除保护和孤儿清理；操作历史不进入同步或 ZIP。

## 连续修改

普通前台任务成功后，以第一张结果建立连续图像对话；多图结果允许你明确选择其他结果作为锚点。工作台用紧凑横向时间线显示轮次、两行要求摘要、结果缩略图、当前锚点和分支关系，你可以查看大图、编辑此图，或从任意历史结果「从此继续」创建新分支。

上下文如何延续取决于链路：

| 链路 | 上下文方式 |
| --- | --- |
| `Responses API` | 父轮 Response ID、配置 ID 与配置修订都一致，且继承参考图未被删除时，使用 `previous_response_id` 与 `action=edit`；新轮只上传新增参考图或本地编辑底图 |
| `Images API`、旧后端、无会话能力的中转站 | 本地兼容上下文，携带初始要求、最近最多 20 轮，总长度最多 64000 字符；界面会显示实际携带的历史轮数 |

配置、地址、协议、主模型或当前图片模型变化，以及继承参考图被删除时，下一轮会明确重建上下文。Response ID 缺失、上游拒绝或过期后不会自动重发，需要你确认「重建上下文」再手动生成。只有生成成功并完成本地持久化后才会前移锚点，失败、取消和迟到响应都不改变当前轮次。

编辑当前连续结果时，产物原子替换连续底图，不会新增或重排普通参考图，也不会退出连续模式；历史遮罩和标记只属于原轮次。「退出连续对话」保留当前普通参考图选择，不删除任何图片资产。连续关系、父任务、选中结果、实际上下文模式和上游 Response ID 会随同步与备份保存；单会话项目包导入后引用重映射，原站点的 Response ID 失效并安全重建。连续修改与生图队列互斥，切换模式不会取消已提交的后台任务。
