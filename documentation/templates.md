# 模板广场与导入导出

> 公开模板的浏览、点赞与收藏，以及管理员导出和合并导入模板包的方式。

模板广场是实例内的公开模板库。管理员把提示词、参数和参考图整理成模板，你浏览后可以套用到自己的工作台；浏览和点赞不需要登录，收藏会把模板快照存进你自己的收藏夹。

## 浏览与筛选

搜索不是即时过滤：在搜索框输入关键词后，按回车或点搜索按钮才会提交查询。标签筛选是多选，多个标签之间按 AND 组合，只有同时含有这些标签的模板才会出现。排序有两种：

| 排序 | 含义 |
| --- | --- |
| 最新发布 | 优先展示最近更新的模板 |
| 最多点赞 | 优先展示点赞数更高的模板 |

列表首屏先挂载 8 张卡片，向下滚动时继续分批补齐；单页累计到 24 张后改为翻页，页码与当前筛选、排序条件一起生效。

## 卡片与详情

卡片信息按固定层级排布：标签固定一行，提示词固定两行，底部操作区保持单行，点赞图标与数字居中显示，点赞数用截断式三位缩写。已审批管理员会额外看到右上角的编辑入口。

打开详情后布局尺寸固定：结果图居中，参考图、配置信息和操作区固定在右下角，把主要空间留给提示词。详情图支持全屏查看、滚轮缩放和左键拖拽。详情中的喜欢、分享、收藏按钮与外层卡片保持一致；收藏时可以选择收藏夹，按钮显示填充状态，再点一次即取消。

## 收藏模板

模板收藏保存的是一份可在本地使用的快照，因此断网也能回看提示词和图片。收藏属于全局收藏夹，不属于某个会话：只有一个收藏夹时点击直接加入，有多个时先弹出文件夹选择。已收藏的模板再次点击收藏按钮，可以移动到其他文件夹或取消收藏。

## 创建与管理模板

只有已审批管理员能创建和修改模板。模板编辑器里的推荐模型、宽高和状态合并成紧凑的一行，宽高是双输入框；状态可选 `draft`（草稿）、`published`（已发布）和 `archived`（已归档），广场默认只展示已发布模板。

标签使用结构化编辑器：可以按分类浏览、多选已有标签，也可以新建分类标签或未分类标签。批量粘贴时支持中文逗号、顿号、分号和换行作为分隔符，一次贴入多个标签。

> ⚠️ **带独立遮罩的任务不能直接发布为模板**
>
> 局部修改产生的底图与遮罩是独立资源，直接发布会丢失这部分输入。用该任务的最终结果图新建一个普通模板即可。

## 导出模板包

导出仅对已审批管理员开放，有两种范围：

| 范围 | 内容 |
| --- | --- |
| 完整备份 | 全部分类的草稿、已发布和已归档模板，以及完整图片资源 |
| 分类分享 | 按分类和标签挑选要分享的模板 |

分类分享时，所选分类与具体标签之间是 OR（命中任意一项即可），状态作为附加条件叠加。导出前会先显示预览：匹配的模板数、去重后的原图资源数，以及原图合计体积（不是 ZIP 文件大小）。筛选覆盖全部分页，不受当前浏览页影响。

模板包保留模板 UUID、完整标签、提示词、生成参数、预览图和参考图。下载文件名形如 `mew-gallery-share-20260913.zip`，完整备份则用 `backup` 前缀。

## 合并导入与冲突

导入采用合并模式，同名模板由你选择冲突策略：

| 策略 | 行为 |
| --- | --- |
| 保留本地版本 | 跳过包内与本地同 ID 的模板 |
| 使用包内版本 | 覆盖本地同 ID 的模板 |

图片 ID 出现在包内但内容不同时，会重新分配 ID 并重写包内引用，从而保护包外的模板和共享图片。模板包是 Schema v1 的 ZIP（`archive_kind=gallery_templates`、`schema_version=1`），不绑定原账号、域名或服务器，可以在不同站点之间自由分享。

## 导入导出的校验与配额

导入会先校验：已审批管理员鉴权、接收站点配额、危险路径、重复条目、异常压缩比、单文件大小、文件格式、图片尺寸和 SHA-256。资源先写入临时 staging 目录，再通过对象存储与 SQLite 事务提交，校验或写入失败时不会改变现有广场内容。

> ℹ️ **广场使用独立的资源配额**
>
> 模板广场的图片保存在公共命名空间，与登录用户的个人图片存储分开计算，配额包含派生缩略图。达到上限后，管理员仍可删除旧模板。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MEW_GALLERY_ASSET_QUOTA_MIB` | `5120` | 广场公共资源总配额（含派生缩略图） |
| `MEW_GALLERY_ASSET_QUOTA_COUNT` | `20000` | 广场资源文件数量上限 |
