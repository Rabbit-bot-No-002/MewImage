# 主题与外观

> 三套主题、明暗模式、装饰档位与自定义背景的完整设置说明。

主题风格和明暗模式是两个独立选项：风格决定特征色与装饰，明暗模式负责背景、面板和文字的对比度。默认组合是「极光星轨 + 日间」。所有设置都在右上角设置菜单的「外观」页里，改完即时生效。

## 主题风格

| 主题 | 视觉特征 |
| --- | --- |
| 经典 Mew | 柔和粉蓝配色与轻量点状纹理 |
| 极光星轨 | 冰蓝星图与深靛天文仪轨道 |
| 液态玻璃 | 低模糊、高透明与柔和折射光纹 |

明暗模式有日间、夜间和跟随系统三档，与主题风格任意组合。

## 极光星轨

极光星轨不是经典主题的换色版本，它在日间和夜间呈现两套观感：日间是冰蓝星图纸，夜间是深靛天文台。青蓝到紫罗兰的渐变用于主操作、选中和焦点状态；粉色只出现在 Logo、星体和少量高光点缀上。

它的大型面板使用高 Alpha、约 18px 模糊的冷色磨砂材质。页面上的装饰由星场、极光帘、天球仪弧线、流星轨迹和星图节点构成，分布刻意不均匀，不会退化成规则网格。

## 液态玻璃

液态玻璃覆盖工作区、画廊、设置、弹窗和菜单，面板使用低 Alpha、约 5px 的大型面板模糊，附带玻璃高光与折射光纹。画廊里重复出现的卡片不会各自再开一层背景模糊，关键操作按钮仍然使用实色强调，避免整页糊成一片。

## 经典 Mew

经典 Mew 保持柔和粉蓝的基础色，用轻量点状纹理做背景层次，是最克制的一套。

## 页面装饰

「外观」页里的页面装饰有三档：

| 档位 | 效果 |
| --- | --- |
| `关闭` | 不渲染主题装饰层 |
| `柔和` | 降低装饰强度 |
| `标准` | 主题的完整装饰效果，默认档 |

移动端会降低星场密度并隐藏大型边缘装饰，装饰层本身不会挡住正文和操作。

## 自定义背景

自定义背景位于主题底色与装饰层之间，上传后可以单独开关。可调参数如下：

| 参数 | 可选范围 |
| --- | --- |
| 填充方式 | `覆盖`、`完整显示` |
| 背景位置 | 九宫格：左上、上方、右上、左侧、居中、右侧、左下、下方、右下 |
| 透明度 | 0%–100% |
| 模糊 | 0–24 px |
| 遮罩 | 0%–90%，用于保证文字和面板可读 |
| 背景图层 | 位于主题装饰下方、覆盖主题装饰 |

「外观」页另有「卡片不透明度」，范围 20%–100%：100% 是主题默认效果，调低可以让自定义背景透过页面卡片，最低保留 20% 以维持内容边界。

背景文件的要求如下：

| 限制项 | 数值 |
| --- | --- |
| 输入格式 | 静态 PNG、JPEG、WebP |
| 输入文件大小 | 不超过 15 MiB |
| 解码后像素 | 不超过 5000 万像素 |
| 最长边 | 不超过 4096 px |
| 处理后格式 | 统一转为保留 Alpha 的 WebP，质量 0.8 |
| 处理后大小 | 超过 8 MiB 时拒绝保存 |

> ⚠️ **动画 WebP 不受支持**
>
> 背景只接受静态图。选到动画 WebP 会被拒绝，请先导出其中的一帧。

## 背景存在哪里

背景的二进制 payload 独立保存在 IndexedDB，不写进偏好 JSON；资源元数据里用 `asset_role=theme_background` 标识。它复用现有的图片对象存储、SHA-256 校验和删除墓碑，但不会进入画廊、参考图列表、任务完整性检查，也不会进入单会话项目包。

背景会随手动云同步上传与恢复，完整工作区 ZIP 也包含背景和外观设置。替换背景时，只有新文件完整转码并写入成功后才会删除旧文件。

## 浮层、下拉与滚动条

菜单、确认框、设置、详情和编辑器等浮层使用独立的高可读材质，不受卡片不透明度滑杆影响，因此三套主题在日夜模式下都能保持稳定的文字、边界、悬停与选中对比度。原生下拉选项在经典和极光星轨的夜间模式使用深色底；排序、标签筛选、服务商、收藏夹等自绘菜单会限制在视口内。网页滚动条改为跟随主题的细圆角样式，可选择按钮统一强化当前项的填充状态。

危险按钮中的文字和图标保持白色，避免与强调背景混在一起。外观设置只能调整主题、装饰档位和背景显示参数，无法注入任意 CSS、HTML 或脚本。

## 无障碍与动效

系统启用「减少动态效果」时，极光漂移、星轨浮动和扫光动画会全部停止。极光星轨的全屏动态层只使用 `transform` 与 `opacity` 动画。
