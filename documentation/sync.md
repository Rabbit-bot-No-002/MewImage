# 手动云同步与数据管理

> 同步什么时候跑、同步哪些数据、API Key 怎么处理，以及本地和云端数据的清除方式。

同步是增强能力，不是使用前提。登录并审批通过后，本地工作区仍然优先；只有点「立即同步」才会执行上传、拉取和合并，同步失败不会破坏本地工作区，服务器也不参与日常输入和看图。

## 同步范围

| 进入同步 | 不进入同步 |
| --- | --- |
| 服务商配置（含模型列表） | 队列开关，只保存在本机 LocalStorage |
| 会话与草稿 | 编辑器操作历史 |
| 生成任务 | 单会话项目包里的全局偏好 |
| 收藏状态与收藏夹偏好 | 明文 API Key（另见下节） |
| 参考图和结果图的资源引用 | |
| 界面偏好，含外观与自定义背景 | |
| 图片远程对象键 | |
| 删除墓碑 | |

单会话项目包是例外：它只带会话草稿、任务、结果原图和参考图，不含服务商配置、API Key、全局偏好、收藏夹、同步检查点或删除墓碑；操作历史同样不进同步和备份 ZIP。

## 同步协议

服务端按用户保存一份快照 `SyncEnvelope`，`schema_version` 为 `3`，覆盖配置、任务、会话、资源和偏好。合并规则：

- 以稳定 ID 和 `updated_at` 做并集，一般冲突取较新的一方；图片记录时间相同时，保留带远程对象键的那条。
- 删除会生成 `Config`、`Task`、`Thread` 或 `Asset` 墓碑；墓碑与实体按时间竞争，时间相同时删除优先，并长期保留。
- 收藏文件夹按稳定 ID 和自身更新时间合并，删除文件夹用独立墓碑。
- 旧版 v1/v2 快照可读，首次由新版同步后升级为 v3。

## 图片如何同步

图片原文件逐张上传，不放进最终的同步 JSON；每成功上传一张就保存远程对象键，中途失败后下次只处理剩余图片。当前设备缺少原图时不会整体中止，而是按资产 ID、SHA-256 和云端索引恢复；只有本地和云端都缺失时才提示无法恢复，并继续同步其余数据。

图片存放位置由 `MEW_ASSET_STORE` 决定，可选 `local`（宿主机 `./data/assets`）、`s3`（S3 兼容对象存储）或 `disabled`。

## API Key 如何处理

API Key 同步默认可关闭。启用时浏览器按用户 ID 和密码派生可信设备密钥，Key 用 AES-256-GCM-SIV 加密后才进入同步快照；云端只有密文、盐、nonce 和提示信息。新设备需输入账号密码解锁密文，改密后下次同步用新密钥重新加密。

> ℹ️ **代理请求期间的明文 Key**
>
> 游客走代理生成时，API Key 只在请求期间进入后端内存，不写入数据库、对象存储和业务日志。生成代理期间后端必然会短暂接触明文 Key，但不会持久化。

跨站导入模板包或项目包后，连续会话里的旧 Response ID 会自动失效并安全重建。

## 本地数据管理

设置里的「数据管理 · 本地数据」提供四类动作：

- 导出 ZIP：版本化 `manifest.json` 加独立 `assets/` 图片，按 SHA-256 去重，不含明文 Key。
- 合并导入：按稳定 ID、更新时间和 SHA-256 与现有数据合并。
- 单会话项目包：导入时始终新建会话、任务和图片 ID，并清除收藏状态与旧远程地址。
- 分类清除：可分别清除历史与图片、服务商配置、界面偏好或全部本地数据。

本地清除不会自动删除云端数据。正在生成图片时，导出、导入和清除都会被挡住，避免异步结果覆盖。

## 云端数据

云端数据只对已审批登录用户开放：可查看服务器图片数量、占用空间、服务商模板和同步快照状态，也可分别清除同步数据与图片、服务商模板或全部云端数据。清除只影响当前账号，浏览器里的工作区和账号都会保留。

## 本地优先意味着 IndexedDB 才是主数据

> 🛑 **不要用浏览器的「清除网站数据」**
>
> 浏览器 IndexedDB 是本地工作台的主数据源，服务端保存的只是你上次同步时的旧快照。按注册域「清除网站数据」会一次性清掉 IndexedDB、LocalStorage 和缓存，包括尚未同步过的历史、会话、参考图、收藏和本地配置；这些不会自动回到服务器，只有上次同步前已上云的部分才可能靠「立即同步」拉回。要清数据，请用设置里的本地清除入口。

## 服务端备份与恢复

服务端只掌握已同步的数据，它自己的备份也要做：

1. 备份整个 `./data` 目录，其中包含 `mew-image.db` 和 `assets/`。
2. 一并保存 `.env`，尤其是 `MEW_AUTH_SECRET` 和 `MEW_MANAGED_PROVIDER_SECRET`；后者需与数据库一起备份，丢失后已有托管配置无法恢复。
3. 恢复时把 `./data` 和 `.env` 放回原位，确认容器内的 `10001:10001` 仍有写权限，再启动服务。

服务恢复后，在你自己的浏览器里登录，再点「立即同步」把服务端快照拉回本地。若不想在新设备上解锁云端密文，先在「账号与同步」里关掉 API Key 同步再同步。
